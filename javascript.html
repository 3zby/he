خطة 5 أسابيع في جافاسكربت

الأسبوع 1 — لغة البرنامج

المتغيرات let / const، الأنواع، العمليات، والنصوص القالبية `مرحبًا ${name}`.

الأسبوع 2 — المنطق

الشروط، الحلقات، والدوال. اكتب دالة تحسب معدلك من مصفوفة درجات.

الأسبوع 3 — المصفوفات والكائنات

map / filter / reduce، ثم الكائنات { } لتمثيل بيانات حقيقية.

الأسبوع 4 — التعامل مع الصفحة

اختيار العناصر querySelector، تغيير المحتوى والأنماط، وربط الأحداث بالأزرار.

الأسبوع 5 — مشروع تفاعلي

قائمة مهام، لعبة ذاكرة، أو حاسبة — بنظرة واحدة على localStorage لحفظ البيانات.

الفرق السريع

HTML و CSS و JavaScript — من يعمل ماذا؟

HTML

الهيكل

يحدّد ما موجود: عنوان، فقرة، صورة، زر. مثل طوب البناء.

CSS

المظهر

يحدّد كيف يبدو: الألوان، الخطوط، المسافات، والترتيب حسب حجم الشاشة.

JavaScript

السلوك

يحدّد ماذا يحدث: عند الضغط، عند الكتابة، وعند وصول البيانات.
