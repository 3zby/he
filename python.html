🌐 الوضع الأول: بايثون الحقيقي

يحمّل مترجم Python حقيقيًا داخل المتصفح (مرة واحدة فقط). يدعم كل شيء: الدوال، القواميس، المكتبات. يحتاج اتصال إنترنت.

⚡ الوضع الثاني: المحاكاة

يعمل بدون إنترنت. يكفي لتجربة المتغيرات والعمليات والحلقات والشروط و f-string. لا يدعم def ولا الاستيراد.

💡 نصيحة للتعلم

لا تقرأ الكود فقط — اكسره! غيّر رقمًا، احذف علامة، أضف سطرًا. رسالة الخطأ هي أفضل معلّم لديك.

الأسبوع 1 — الأساسيات

المتغيرات، الأنواع (نص، رقم، منطقي)، الدوال الجاهزة مثل print() و input()، والعمليات الحسابية.

الأسبوع 2 — القرارات والحلقات

if / elif / else، وحلقة for مع range()، و while. ابنِ جدول الضرب ومحادمة بسيطة.

الأسبوع 3 — المجموعات والدوال

القوائم list، النصوص ودوالها، ثم تعريف دوالك الخاصة بـ def مع المعاملات والإرجاع.

الأسبوع 4 — مشروع حقيقي

اختر فكرة: آلة حاسبة، لعبة تخمين، منظّم مهام، أو برنامج يحسب معدلك. اعرضه في ختام الفعالية.
