جرّب هذا الآن

التصميم المتجاوب: موقع واحد لكل الشاشات

لهذا الموقع نفسه 4 مستويات استجابة. جرّب زر «📱 جوال» فوق المعاينة لترى الفرق.

صندوق واحد لكل العناصر

ضع *{box-sizing:border-box} في أول ملف CSS — يمنع مفاجآت العرض.

وسم الـ viewport

<meta name="viewport" content="width=device-width"> — بدونه يظهر الموقع مصغّرًا على الجوال.

خطوط تتنفّس

استخدم clamp(1rem, 3vw, 2rem) بدل الحجم الثابت، فيكبر الخط مع الشاشة تلقائيًا.

شبكة مرنة

grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)) تُعيد ترتيب البطاقات وحدها.

استعلامات الوسائط

@media (max-width: 768px){ … } لتغيير الترتيب على الشاشات الصغيرة.

اختبر بيدك

افتح موقعك على جوالك الحقيقي — أسرع اختبار وأقرب نتيجة للواقع.

صفحة تعريفية عن نادي البرمجة

HTML فقط: عنوان، فقرات، صور، وقائمة بالمشاريع. تتعلّم بنية الصفحة.

أضف هوية بصرية

CSS: ألوان المدرسة، خط عربي مناسب، بطاقات، وزر مميّز بتأثير عند المرور.

أضف تفاعلاً

JavaScript: زر تبديل الوضع الليلي، نموذج تسجيل، وعدّاد للزوّار.

أطلقه على الإنترنت

ارفع الملفات على GitHub Pages أو Netlify مجانًا، وشارك رابط موقعك مع زملائك.

شغّل أول مثال، صوّر النتيجة، وأحضرها لاجتماع النادي القادم.
